两种打法，一场夺床对决。

AI 在真实 Minecraft 服务器里收集资源、采购装备、搭桥交战。摧毁对方的床，再拿下最后一次击杀。

原版 Java 1.21本地 AI，无云模型调用九座岛 · 双队 1v1离线可观看
请先将整个 ZIP 解压，再打开 index.html。也可以直接打开 assets 文件夹中的 MP4 视频。
视频来自实际比赛记录的平视 3D 回放。完整比赛按原速播放；片段剪辑会省略间隔。该视频没有游戏音轨。

两名示例 AI

EmberAI · 进攻

轻量护床后准备工具、搭桥施压。根据眼前的床防决定挖掘或爆破，抓住露床窗口；血量不足时尝试撤退补给。

快攻 / TNT / 近战推进

BastionAI · 防守

先拿基础武器，再布置防爆内层。积累资源购买持久装备和团队升级，在有条件时利用弓箭、高地及反击。

护床 / 经济 / 远程控制

从资源争夺到最终淘汰

床还在时，死亡后等待 5 秒复活；床被拆后，再次死亡就会淘汰。铁、金购买基础装备，钻石升级团队，绿宝石购买高级物品。20 分钟移除剩余床，25 分钟开始缩圈，30 分钟结算。
