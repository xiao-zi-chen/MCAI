# 悬空夺床 · skyduel-0.6.0

本文件由当前模式的 `rules.json` 生成。状态为本地规则测试版；修改数值后必须重新生成，并给正式赛事发布新的版本。主办方负责地图、规则、裁判、运行和回放；参赛者自行编写策略或训练模型。训练模型不是报名的强制条件。

## 原版机制与起床战争规则

本赛项以 Minecraft Java 1.21 为基准。Minecraft 官方没有统一的起床战争商店、价格和复活规则；以下清楚区分原生行为与本赛项扩展。它不使用 1.8 的无冷却连点战斗。

| 范围 | 规则来源与实际行为 |
| --- | --- |
| 移动、碰撞、跳跃、潜行、游泳、楼梯 | Minecraft Java 1.21 原生物理；AI 发送正常玩家操作，不改速度或抵消击退 |
| 攻击、暴击、护甲和挖掘速度 | Minecraft Java 1.21 原生计算；剑存在攻击冷却，斧与剑的攻击速度不同 |
| 吃金苹果与喝药 | 原生持续使用，通常 32 刻（1.6 秒）；中断使用不会获得完整消耗效果 |
| 拉弓与放箭 | 原生蓄力，20 刻（1 秒）达到满蓄力；箭消耗、飞行与伤害交给服务器 |
| 金苹果效果 | 原生再生 II 5 秒、伤害吸收 I 120 秒；吸收生命与普通生命分别记录 |

| 自动点燃 TNT、可投掷火球、防爆玻璃 | 起床战争扩展；普通生存中的 TNT、火焰弹和玻璃没有这些默认行为 |

## 游戏规则

- Minecraft Java 1.21 / Paper 130 / Screaming BedWars 0.2.44。
- 2 队各 1 人，开局倒计时 15 秒，每局最多 1800 秒游戏时间。卡服时不按墙钟提前结算。
- 九座悬空岛，左右镜像；包括两座基地、两座前哨、四座钻石岛和中心绿宝石岛。 主桥留有缺口，需要选手搭建；原始建筑受保护。
- 初始 20 生命和一把木剑；无饥饿、无自然回血，金苹果效果按 Minecraft 1.21 处理。剑冷却、击退、暴击和挖掘时间采用固定版本原版机制。
- 以死亡时的床状态判定复活资格：死亡时床存在，5 秒后在己方基地复活，获得木剑和 3 秒出生保护。倒计时期间床被拆，已经获得的这一次复活仍可完成；床被拆后再死亡，最终淘汰，不能复活。等待复活的旁观状态不显示为赛场角色。
- 初始皮甲；购买锁链、铁、钻石护甲升级护腿和靴子，头盔与胸甲保持队色皮甲。护甲永久保留，镐/斧死亡降一级、最低木制；剪刀保留。其余随身物品死亡掉落；箱内物资保留到本局结束。永久装备不能丢弃，重复购买同级或较低装备退回费用。
- 永久装备不生成地面掉落物，也不能存入箱子复制。工具可直接购买任意已列出的等级，按表格收费；商店没有列出的工具等级不可购买。普通箱可被各队访问；末影箱按玩家隔离，同一玩家可以从任意末影箱访问自己的储物。允许存取铁、金、钻石、绿宝石。
- 床被拆后当前玩家可以继续行动，但下次死亡最终淘汰。全队最终淘汰后该队出局；只剩一队时全队获胜；同时淘汰或到达时限后多队仍存活则平局。
- 只允许在赛区内放置/破坏参赛者放置的方块及敌方床；原始岛体受保护。建造范围为 [-72, 0, -42] 至 [72, 96, 42]，按方块坐标含边界。
- 商店、装备和资源固定，不允许创造模式、非法飞行/位移、管理命令或修改裁判；末影珍珠属于允许的游戏内传送道具；实际到达商店范围、资源足够且背包可容纳时才能成交。
- 提供团队升级、弓箭、金苹果、自动点燃的 TNT、火球、末影珍珠、水桶和速度/跳跃/隐身药水。玻璃防爆；黑曜石需要合适工具，原始地图不受爆炸破坏。药水等级和时长由下表固定，隐身保留原版的装备可见性。它不会像部分 BedWars 插件那样额外隐藏盔甲。

## 特殊物品的明确参数

- 自动点燃 TNT：放置即点燃，80 刻（4 秒）引信，爆炸威力 4，会伤害放置者。爆炸威力不是固定生命伤害。
- 火球：右键发射是 BedWars 扩展，爆炸威力 3，会点火，也可能伤害发射者。Screaming BedWars 将火球对玩家的基础伤害设为 3 点，装备和效果再影响最终损伤；这项伤害设置属于插件扩展。
- 防爆白色玻璃免于本赛项爆炸拆除；原始地图方块也受保护。普通生存中的玻璃不具有这项特权。

## 团队升级与比赛阶段

到己方升级商人处购买，每项按等级依次扣除钻石；升级作用于当前队伍整局。

| 升级 | 各级钻石费用 |
| --- | --- |
| 锋利武器 | 4 |
| 护甲保护 | 2 / 4 / 8 / 16 |
| 急迫采掘 | 2 / 4 |
| 资源熔炉 | 2 / 4 / 6 / 8 |
| 基地治疗池 | 1 |
| 警报与失明陷阱 | 1 / 2 / 4 |

锋利 I；保护 I–IV；急迫 I–II。熔炉 I/II 将铁金每轮产量提高至 2/3，III 解锁基地绿宝石（30 秒），IV 铁金产量提高至 4、基地绿宝石间隔 15 秒。治疗池在出生点 8 格内给予再生 I。陷阱最多存 3 次，敌人进入出生点 9 格范围时消耗一次，施加 5 秒失明/缓慢、解除隐身并提醒队友；触发间隔 15 秒。

| 比赛时间 | 事件 |
| --- | --- |
| 6:00 | 钻石生成数量升级，等级 2 |
| 12:00 | 绿宝石生成数量升级，等级 2 |
| 18:00 | 钻石生成数量升级，等级 3 |
| 20:00 | 所有存活的床消失 |
| 25:00 | 边界开始向中心收缩 |

突然死亡阶段，边界在 180 秒内从 152 格收缩到 16 格；越界按规则受伤。到 30 分钟仍有多队存活则平局。每局结束恢复床、方块、生成器和边界，清空装备与升级。

## 对阵与判分

同一对手交换红蓝各打一局；胜 3 分、平 1 分、负 0 分。比较同一赛程的积分，同分保留并列，不用伤害、采集或普通击杀破平。平台故障作废重赛；参赛策略运行故障的正式裁定还需要接入 AGX 执行器。本地调度器保存每名选手的场次和胜场，中止或测试局不计胜场。

## 投稿与观察合同

提交单个 UTF-8 `agent.js`，同步入口 `act(o)`。允许算法策略或内嵌权重的本地推理；不允许联网、读宿主文件或调用云端模型。比赛间清空运行上下文；本局可以使用 JS 全局变量记忆历史。正式比赛运行提交时冻结的源码版本。

自身位置、血量、背包、装备与冷却可见；初始静态地图、商店价格、资源点和床状态公开。对手仅在 16 格内且无遮挡时出现；隐藏位置、精确血量、背包、冷却和策略源码不提供。动态方块只公开当前可见部分，选手可以记住历史观察。可使用 16 格内实际收到的方块音效及其位置进行判断，音效不附带隐藏敌人的身份或实时坐标。观察与动作的完整约定见 `CONTRACT.zh-CN.md`，动作结构见 `action.schema.json`。

策略每 4 个游戏刻度调用一次，同一轮冻结观察并在统一后续刻度应用动作。平台辅助寻路、搭路和瞄准必须公开、版本固定，并受相同合法观察限制。

候选预算：源码 4 MiB、堆 128 MiB、栈 1 MiB、初始化 2000 ms、单次回调 20 ms、每席每局累计 CPU 30 秒。预算仍需完整比赛执行器压测后冻结；目前不能把这些指标说成已经由 Minecraft 插件强制执行。
