# v0.4 行为与观战修正

之前的“机制通过”不能证明 AI 的决策合理。已有网络只在小规模近战环境中训练，整场起床战争依靠公开策略程序；本次没有重新训练网络，也不能据此声称达到高手或视频作者的水平。

复盘发现，旧进攻路线对完整道路也逐格重新寻路，近战随机抽取的动作含停步，守桥分支没有等待上限。旧比赛 `fc37998e-c815-42f1-8b55-53bdb6359876` 中，BastionAI 连续约 1107 秒几乎不移动。浏览器当时只移动静态人物模型，并未还原手脚和实际装备。

| 问题 | 当前处理 |
| --- | --- |
| 逐格停顿、重复搭桥、隔空追敌 | 根据实际方块规划路线，优先已有路，只补缺口；连续直线路段一次行走，到转弯再调整。远端未加载时先经过公开的中央落点。 |
| 桥边斜切和乱跳 | 关闭寻路器的跨缺口跳跃；预测行进方向的落脚面，用真实潜行动作保护边缘；没有修改速度或抵消击退。 |
| 近战停顿、出手与距离不匹配 | 已有网络建议侧移，执行器单独判断距离、视线和原生攻击冷却；接敌前取剑，保持短时间稳定的走位。 |
| 放完 TNT 后空手长时间等待 | 按剩余引信时间撤离、取剑，在爆炸前应对近处敌人；防守方看到附近点燃的 TNT 会寻找撤离点。 |
| 拆完床还继续拆保护层 | 敌床消失后转为追击，使用可见敌人及短期记忆；没有读取远处隐藏敌人的实时位置。 |
| 囤积物资却不升级 | 采购预算计入自己末影箱中已存资源；需要时取回，购买永久护甲和道具。挖掘优先选对应工具，避免用金锭等资源充当工具。 |
| 角色滑动、看不出手持物和护甲 | 位置插值、按真实移动距离摆动手脚；挥手、受伤、挖掘、潜行和使用物品从裁判事件/状态还原；显示红蓝皮甲、升级后的护甲及手持物，第一视角也显示手持物。 |
| 地图缺乏可用路线 | 新地图 `sky-lanes-2.0` 将钻石岛移到两侧，提供正面桥口、资源分路和中央掩体；标出商店、升级与资源点。旧世界及其回放地图快照保留。 |

EmberAI 仍偏快速施压、TNT 和药水突袭。BastionAI 偏分层防御、持久装备、远程拦截、资源升级与回防。二者使用同一套合法动作与地形约束，没有为某方强制安排胜负。

## 验证与证据

- 规则生成检查：`competition/test_rules.py`。
- 路线、攻击、资源使用与残局回归：`scripts/bedwars-skills.test.cjs`、`scripts/advanced-tactics.test.cjs`。
- 观战插值、真实动作驱动、回退与地图一致性：`local-viewer/*.test.cjs`。
- 新地图上的 16 项实服道具/策略验收：`runs/tactics-verification.json`；这是一局明确标记为 test 的管理员设定场景。
- 普通完整比赛与逐段观察：`runs/showcase-v4/final-match-observation.json`。记录会核对运行控制器哈希，开发中断局不计入完整比赛。
- 浏览器角色、手持物和旧回放兼容检查：`runs/showcase-v4/actor-browser-check.json`。
- 分析工具：`scripts/analyze-bedwars.cjs <match-id>`。旧回放没有伤害/挥手记录时返回 null，不把缺少记录解释为没有攻击。

这些检查能验证具体行为与数据一致性，不能替代大量交换出生侧的对战、不同地图测试或与真人高手的比较。宏观策略仍是程序；复杂掩体、远程预判和临场取舍仍可能出错。网页是按 5 Hz 服务器记录重建的观战画面，尚非完整原版客户端的动画、粒子和界面。AGX 的正式投稿执行器、隔离与赛程集成仍未完成。

控制器 `022a410611fe7792d00c5094ca155c93ef417d52639a0fa9be015f600837c4c5` 完成了两局正常比赛，并交换出生侧：

| 比赛 | 时长 | EmberAI / BastionAI 实际近战命中 | 结果 |
| --- | --- | --- | --- |
| 9066f121-64a8-4e20-b8db-4a3882e94218 | 2:32 | 16 / 7 | EmberAI（红队）获胜 |
| fcfcac29-81fb-4ace-be25-6837355636b7 | 2:27 | 10 / 6 | EmberAI（蓝队）获胜 |

两局均有补桥、近战和拆床；记录还包括 TNT、治疗、资源采集与药水。这两局没有虚空伤害死亡，最长静止约 25 秒，位置在基地资源点；并不代表所有对局都不会失误。EmberAI 两局均获胜，防守策略尚未证明与快攻策略平衡。运行中仍有可恢复的寻路失败。

自动检查为 31 项 Node 测试和 13 项规则测试，共 44 项。浏览器检查没有脚本错误或缺失素材，暂停时动作保持不变，390px 页面无横向溢出。最终报告为 `runs/showcase-v4/quality-report.json` 和 `final-browser-check.json`。实际交战片段已导出为 `runs/showcase-v4/combat-preview.webm`。
