## 本地策略设计

以下是基于公开玩法与本地测试设计的策略，不是对某位博主操作的逐帧模仿。

| 局势 | 决策 | 验收证据 |
| --- | --- | --- |
| 看到敌人进入床附近 | 打断资源行程，优先拦截 | 决策历史与玩家移动 |
| 危急低血量 | 脱战，能治疗时用遮挡与金苹果 | 血量、效果、消耗记录 |
| 快攻准备 | 羊毛与基础工具，优先携带 TNT | 实际商店扣款与爆炸 |
| 防守准备 | 末地石内层、羊毛外层，发现缺口修补 | 方块放置与破坏记录 |
| 收获钻石 | 优先保护/陷阱/锋利，按余额升级 | 团队升级事件 |
| 有多余物资 | 存末影箱；补给缺钱时取回 | 真实容器库存变化 |
| 敌人站在桥上 | 满足距离与视线时发射火球 | 弹体、消耗与击退 |
| 进攻途中 | 合适距离使用药水，再接近基地 | 原生状态效果 |
| 桥头受阻或丢床 | 有珍珠时选择实心岛体落点 | 物品消耗、实际落点 |
| 看到敌方床防 | 按材料选工具，玻璃/黑曜石不用 TNT 硬炸 | 工具与挖掘/爆炸记录 |

策略只应使用自身状态、公开静态地图/床状态、当前可见对手；没有隐藏敌人追踪与敌方血量。宏观规划由公开程序执行；v0.4 的已有模型建议近战侧移，距离、冷却和地形约束由控制器执行。增加策略分支不等于增强已获证明，需要完整实战和对照评估。

## 与常见视频的区别

本服固定 Minecraft Java 1.21，按原版攻击冷却、盾外装备规则与药水机制运行。许多 Hypixel 视频使用 1.8 系列机制，连点、击退与特殊物品效果不能直接照搬。当前 1v1 也不能把多人分工战术视为已经实现。

正式投稿执行器、预算强制执行、AGX 排名仍待接入。尚不能把当前测试版称为完整复刻任一商业 BedWars 服务器。
