## 不能声称已经完成的内容

- 不能保证 AI 达到高手/博主水平；短期模型评测和道具检查不等于长期胜率。
- 目前不是 4v4、多队、多地图天梯，也未完整复刻某个商业服务器。桥蛋、召唤物、梦境模式等扩展不在本规则包内。
- 正式 AGX 的游戏注册、调度、观察隔离、资源预算、策略故障判负、排名与网页接入还需要后端源代码。
- 浏览器采用简化实体渲染，完整原版画面可用 Minecraft Java 客户端连接本地服务器查看；平视 3D 回放是按记录重建，并非原版客户端录屏。

验收脚本使用管理员设置会标记 test，对局不会混入正常演示回放。参考材料与可访问范围见 STRATEGY_RESEARCH.zh-CN.md。
